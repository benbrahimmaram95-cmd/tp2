Introduction aux Standards Web

Le W3C définit les normes du Web. Initialement, le Web utilisait le HTML 4.01 et HTML5 pour structurer les documents.

Par exemple, la formule de la masse en physique moderne est E = mc2, tandis que la formule de l'eau est H2O.

Citations célèbres

Comme le disait Tim Berners-Lee : Le pouvoir du Web est dans son universalité.

L'accès pour tous, quel que soit le matériel, le logiciel, l'infrastructure réseau ,la langue materielle,la culture,le lieu géographique,ou les capacités physiques ou mentales est un aspect fondamental du Web.
